# Run a School

A Steal-a-Brainrot style school tycoon for Roblox: enroll students off the bus, earn tuition,
steal other players' best students, name and upgrade your school, face the School Board.

- GAME-PLAN.md: design and build order
- CLAUDE.md: working notes and current status
- src/: game scripts (see CLAUDE.md for where each goes in Studio)
- tools/: map builder and checksum tools
